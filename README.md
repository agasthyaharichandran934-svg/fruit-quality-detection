# Fruit Quality Detection

A mini project that classifies fruit images as **Good (fresh)** or **Bad (spoiled)**
using a Convolutional Neural Network (CNN) and transfer learning, with a Flask
web interface for image upload and real-time prediction.

> B.Tech Mini Project — Dept. of CSE (CSD), Vimal Jyothi Engineering College,
> Chemperi (March 2025)

## Project Structure

```
fruit-quality-detection/
├── app.py                     # Flask web app (upload image -> prediction)
├── predict.py                 # Standalone prediction script (CLI / notebook use)
├── train_model.py             # Train a CNN from scratch
├── train_transfer_model.py    # Train using transfer learning (MobileNetV2)
├── prepare_dataset.py         # Organize raw images into train-ready folders
├── fruit_classifier_model.h5  # Trained model (generated by training scripts)
├── requirements.txt
├── templates/
│   └── index.html             # Web UI
├── static/
│   └── style.css
├── raw_dataset/                # Original unsorted images (not tracked in git)
└── dataset/                    # Prepared images for training (not tracked in git)
```

## Setup

```bash
python -m venv .venv
.venv\Scripts\activate        # Windows
pip install -r requirements.txt
```

## Preparing data & training

```bash
python prepare_dataset.py
python train_model.py              # or: python train_transfer_model.py
```

This produces `fruit_classifier_model.h5`.

## Running the app

```bash
python app.py
```

Then open `http://127.0.0.1:5000/` in a browser, upload a fruit image, and
click **Predict**.

## Predicting from the command line

```bash
python predict.py path/to/image.jpg
```

## How it works

1. **Preprocessing**: uploaded image is read with OpenCV, resized to 100x100,
   and normalized to [0, 1].
2. **Classification**: a trained CNN (or transfer-learned MobileNetV2) predicts
   a class such as `Good Orange` or `Bad Apple`.
3. **Quality decision**: if `"Bad"` appears in the predicted label, the fruit
   is flagged **Bad**; otherwise **Good**.
4. **Result display**: shown in-browser via Flask, or via Matplotlib when run
   from the command line.

## Note

Class labels and the specific fruits supported (e.g. orange/apple/pomegranate
vs. banana/strawberry/mango) may need to be adjusted in `predict.py` and
`app.py` to match whatever classes your trained `fruit_classifier_model.h5`
was actually trained on — check `train_generator.class_indices` printed
during training to confirm the exact label order.

## Code Walkthrough

### `prepare_dataset.py`
Takes raw, unsorted images (`raw_dataset/<ClassName>/*.jpg`) and copies them
into a clean `dataset/<ClassName>/` layout that Keras's
`ImageDataGenerator.flow_from_directory()` can read directly — one folder per
class (e.g. `Good Apple`, `Bad Apple`).

### `train_model.py`
Builds and trains a **CNN from scratch**:
- `ImageDataGenerator` loads images in batches and augments them (rotation,
  zoom, shifts, flips) so the model generalizes better with a small dataset.
- The network itself is 3 convolution + max-pooling blocks (32 → 64 → 128
  filters) that progressively extract shapes, textures, and color patterns,
  followed by a dense classification head with dropout to reduce overfitting.
- Trained with the Adam optimizer and categorical cross-entropy loss (multi-class).
- Saves the trained weights to `fruit_classifier_model.h5`.

### `train_transfer_model.py`
Same pipeline, but instead of learning visual features from scratch, it
reuses **MobileNetV2** pretrained on ImageNet as a frozen feature extractor,
with only a small custom classification head trained on top. This is
**transfer learning** — it needs far less data and training time to reach
good accuracy, since the base model already knows general image features.

### `predict.py`
The core inference logic, standalone and reusable:
1. Loads the saved `.h5` model and the list of class labels.
2. `predict_fruit(image_path)` reads an image with OpenCV, resizes it to
   100×100, normalizes pixel values to [0, 1], and adds a batch dimension.
3. Runs `model.predict()` and takes the class with the highest probability
   (`np.argmax`) plus its confidence (`np.max`).
4. Maps the specific class (e.g. `"Bad Apple"`) down to a simple **Good/Bad**
   verdict.
5. Displays the image with the verdict overlaid, using Matplotlib — handy for
   quick command-line testing without the web app.

### `app.py`
Wraps the same prediction logic in a **Flask** web server:
- `GET /` renders the upload form.
- `POST /` receives the uploaded image, saves it, runs `predict_fruit()`,
  and re-renders the page with the result.
- Keeps model loading at import time (once, on server start) rather than
  per-request, so predictions are fast.

### `templates/index.html` + `static/style.css`
The front-end: a file upload input, a Predict button, and a color-coded
result badge (green for Good, red for Bad) — rendered server-side via Flask's
Jinja templating.
